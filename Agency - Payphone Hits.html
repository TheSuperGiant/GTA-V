With the Payphone Hits you will get a base payout and a bonus payout.
The bonus pay is only awarded if you complete the kill using the method described in the job text.
If done wrong, you only get the base pay.
CEO gets: $15,000 + $30,000 bonus = $45,000
Associate gets: $15,000 + $10,000 bonus = $25,000
